# Pointer truncations

Generated by `scripts/port/truncations.py` from the port's compile commands; do not edit by hand.
Every cast of a pointer to an integer narrower than a pointer in `src/ps2`, `src/port` and their
headers. On Linux the port keeps these values alive by linking without PIE and mapping its arenas
below 2 GiB; arm64 macOS can do neither (the low 4 GiB are its hard page zero), so every
**round-trip** site that runs must be widened in `src/port` before the game can run there.
On Linux, `--high-arenas` (or `DC_HIGH_ARENAS=1` for the tests) maps the arenas above 4 GiB, and
linking `darkcloud` as PIE as well puts the image there too: the macOS layout, where a round trip
that runs faults at once.

- **round-trip**: the value comes back as a pointer (cast back, stored or passed into an int that is
  cast back somewhere, returned from a function whose result is cast back, or an absolute address
  added to a pointer as an offset).
- **low-bits**: only the low bits are used (masks, modulo, shifts, differences of two truncated
  pointers, tests, comparisons, a pointer field holding a file offset added to a base).
- **escapes**: stored into memory, an aggregate or an unknown callee, and never seen cast back.
- **resolved**: a round trip whose value only becomes a pointer again in a replaced or dead function
  (the replacement recovers the pointer, e.g. `PortImagePointer` for image globals).

State of the enclosing function in the linked `darkcloud`: **port** (src/port's own code),
**replaced** (a src/ps2 body a src/port definition displaces; never runs), **retail** (a src/ps2
body that is linked and can run), **dead** (dropped by `--gc-sections`; never runs).

Origin is where the pointer points, where the expression shows it: **image** (a global, a literal,
a function), **stack**, **arena** (an arena allocation or global), **parameter**, **field**,
**global pointer**, **local pointer**, **call**, **this**.
