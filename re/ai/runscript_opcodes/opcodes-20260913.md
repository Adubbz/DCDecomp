# `runscript_opcodes` analysis

## Local stack helpers

Retail marks `GetStackInt`, `GetStackFloat`, `GetStackString`, and both
`SetStack` overloads as local functions. Eighty-five residual assembly
functions call the disassembler-suffixed forms. Defining a helper naturally
emits its unsuffixed local name, leaving those residual calls unresolved at
link time. An object symbol rename can bridge that transition while retaining
local binding; the required build configuration belongs to the layout lane.

## `_BOSS_FADE_OUT`

The body exported by Dayuppy calls `EdFadeInit` and starts a 120-frame black
fade, then clears `BtActStatus.unk_064` and sets `BtActStatus.unk_098`. Retail
returns one in `$2`, so the opcode returns `int`. The typed adaptation scores
98.75%; its only differences are the three registers used to distribute the
zero-valued float arguments. Direct literals, a shared local, and separate
colour locals all produce the same allocation, so the function is parked.
