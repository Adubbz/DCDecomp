## Local stack helpers

Retail marks `GetStackInt`, `GetStackFloat`, `GetStackString`, and both
`SetStack` overloads as local functions. Eighty-five residual assembly
functions call the disassembler-suffixed forms. Defining a helper naturally
emits its unsuffixed local name, leaving those residual calls unresolved at
link time. A layout-lane probe renamed all five definitions while preserving
local binding, but retained assembly emitted distinct same-name global
undefined symbols that MWLD did not resolve. The five helpers and 85 callers
therefore remain an atomic cohort and are parked for this wave.

## `_BOSS_FADE_OUT`

The body exported by Dayuppy calls `EdFadeInit` and starts a 120-frame black
fade, then clears `BtActStatus.unk_064` and sets `BtActStatus.unk_098`. Retail
returns one in `$2`, so the opcode returns `int`. The typed adaptation scores
98.75%; its only differences are the three registers used to distribute the
zero-valued float arguments. Direct literals, a shared local, and separate
colour locals all produce the same allocation, so the function is parked.

## `_STOP_LOOP_SND`

The opcode reads the current monster's `MONSTOR_SOUND::sequence_id`. It
returns immediately when no sequence is active; otherwise it clears the ID
and calls `SndSeStop` with the old ID and twice the monster index. Typed forms
using a field pointer, repeated member access, and reordered locals score at
most 97.96%; the remaining differences are only general-purpose register
allocation, so the function is parked.
